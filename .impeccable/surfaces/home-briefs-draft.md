# Home: three art-direction briefs (draft, awwwards-skill phase 1)

Constraints from Ray (2026-10-21): full skill stack (GSAP + ScrollTrigger + exactly one smooth-scroll engine, Lenis; Three.js only if a brief needs it). No build screens, no confirmed photo. Hero focal asset therefore has to be authored type and real data (weeks, results, quote), never a fake dashboard, CSS illustration or invented logo wall. Static first frame complete with no JS. Reduced motion renders final states immediately. Copy limited to facts in content/*.

## A. Weeks (data-led)
Visual thesis: time-to-ship is the proof. Hero focal asset: the four builds as bars on a 0 to 10 week axis, huge serif numerals (6, 8, 10, 4).
Type: grotesk body, one serif for numerals only. Colour: warm white shell, graphite band, no accent.
Sections: hero chart, three services with timeframes, quote, about teaser, book.
Motion narrative: bars draw left to right on load (700ms); pinned scrub moves a playhead across the axis while each build's result line swaps in; numerals count once.

## B. Chapters (type-led editorial)
Visual thesis: work before studio, one case per chapter. Hero focal asset: one huge outcome sentence per project on a muted colour field (green, umber, slate, olive), no imagery.
Sections: chapters 01 to 04 (pinned), services, quote, book.
Motion narrative: scroll scrubs chapter to chapter, colour field cross-fades, headline reveals by masked word (60ms stagger), chapter counter ticks.

## C. The quote (document)
Visual thesis: buying from me looks like a fixed-price quote. Hero focal asset: the quote itself, ruled lines on paper, built line by line.
Sections: quote hero, "how it runs" 4 steps, shipped work table, client quote, book.
Motion narrative: quote lines write in on load; scroll stamps each step and totals the weeks; the table rows rule in.
